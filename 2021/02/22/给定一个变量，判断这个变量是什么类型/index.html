JavaScript 判断数据类型：typeof、toString 与 Array.isArray

2021-02-22 1978 字 4 分钟

JavaScript 有哪些类型

JavaScript 类型分为基本类型和引用类型。基本类型包括 string、number、boolean、undefined、symbol、bigint、null；引用类型包括 object、array、function、date、regexp 等。

typeof 的优点和缺点

typeof 'abc'      // 'string'
typeof 123        // 'number'
typeof true       // 'boolean'
typeof undefined  // 'undefined'
typeof function(){} // 'function'
typeof null       // 'object'

typeof 适合判断基本类型，但 null 会返回 object，数组和普通对象也都返回 object。

Array.isArray

Array.isArray([]) // true
Array.isArray({}) // false

判断数组优先使用 Array.isArray，比 instanceof 更稳。

Object.prototype.toString

Object.prototype.toString.call([])        // [object Array]
Object.prototype.toString.call(new Date()) // [object Date]
Object.prototype.toString.call(null)      // [object Null]

这是最通用的判断方式，可以区分 Array、Date、RegExp、Null 等。

通用函数

function getType(value) {
  if (value === null) return 'null'
  const type = typeof value
  if (type !== 'object') return type
  return Object.prototype.toString
    .call(value)
    .slice(8, -1)
    .toLowerCase()
}

instanceof 的使用场景

instanceof 判断对象是否出现在某个构造函数的原型链上，适合判断自定义类实例。但跨 iframe 或多执行上下文时可能不可靠。

实践建议

  • 判断数组用 Array.isArray。
  • 判断基本类型用 typeof。
  • 写工具函数时用 Object.prototype.toString。
  • 判断 null 要单独处理。

常见痛点

  • typeof null 返回 object：这是历史遗留问题，面试和真实业务里都容易踩坑。
  • 数组和对象混淆：typeof [] 和 typeof {} 都是 object。
  • instanceof 跨环境失效：iframe 或不同 JS 上下文里，原型链可能不是同一份。
  • 工具函数不统一：项目里到处写临时判断，后续边界越来越多。

详细解决方案

业务项目里建议封装一个稳定的 getType，再基于它写 isPlainObject、isEmptyValue 等语义函数。调用方不需要记忆所有底层细节，只表达业务意图。

function getType(value) {
  return Object.prototype.toString.call(value).slice(8, -1).toLowerCase()
}

function isPlainObject(value) {
  return getType(value) === 'object'
}

function isEmptyValue(value) {
  return value === null || value === undefined || value === ''
}

注意空值判断不要误伤 0 和 false。很多表单场景里，0 是合法数字，false 是合法布尔值，不能简单写成 if (!value)。

排查清单

  • 判断数组，用 Array.isArray，不要用 typeof。
  • 判断 null，单独写 value === null。
  • 判断 Date、RegExp、Map、Set，用 Object.prototype.toString.call。
  • 判断业务空值时明确规则，不要把 0、false 当成空。
